# Proposed Codex dispatch

The scoped complaint and verified case/transcript paths satisfy intake and location for this exercise. Before dispatch, I would read the reported transcript region myself using the case file’s context-safety rules. I would make seven analyst assignments; the four available `sp_*` typed roles have different responsibilities and prompts, so none is appropriate here.

For **each** assignment: `spawn_agent({task_name: <dimension name>, fork_turns: "none", model: "gpt-6-sol", reasoning_effort: "medium", message: <complete prompt>})`, omitting `agent_type`. The complete message would contain the absolute `CASE` path, every verified absolute session and associated-subagent transcript path and ID from that case, any assigned `RANGE` (or explicitly “entire scoped session”), the **full verbatim contents** of `prompts/analyst-common.md` and that dimension’s prompt, the context-safety reference path named by the case, and “Do not spawn subagents.” It would require read-only analysis, the common prompt’s exact return format, and `path:line` evidence for every finding. I would copy the verified paths; I would not use a worker’s “current session” or invent paths.

With two slots free, I would dispatch the two dimensions matching the complaint’s quick-reference priority first; if no complaint-specific pair applies, `skill-timeline` and `plan-adherence`. As each finishes, I would fill its freed slot in this stable order, skipping already assigned dimensions: `skill-timeline`, `plan-adherence`, `repeated-work`, `stumbles`, `quality-evidence`, `request-conflicts`, `cost-and-time`. Thus all seven run without reducing depth. If both slots become unavailable, I would wait for a worker to finish before another dispatch; I would not send calls expected to fail. I would discard uncited findings and check cited content before reporting. Long transcripts could receive additional turn-range assignments for a dimension, still within the same slot limit.

Only after an authorized export request and agreed redaction level: dispatch a **fresh generic** scrubber with `fork_turns: "none"`, `model: "gpt-6-sol"`, `reasoning_effort: "medium"`, no `agent_type`; include the full `prompts/scrub.md`, full `references/redaction-policy.md`, exact absolute `BUNDLE` path and file inputs, `PUBLIC_REPOS` and `PROPRIETARY` lists, and “Do not spawn subagents.” Authorize edits only to bundle copies, never source sessions. After it finishes, dispatch a **different fresh generic** auditor with the same parameters except `model: "gpt-6-astra"`; include the full `prompts/scrub-audit.md`, the same policy and exact bundle inputs/lists, and prohibit subagents. The auditor is read-only. On `MISSED`, repeat scrub then independent audit until `CLEAN`; retain the bundle evidence check and approval gates.
