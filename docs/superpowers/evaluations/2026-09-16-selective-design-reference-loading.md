## Baseline before guidance

Five fresh Sol/low no-guidance notes and five fresh Sol/low current-skill notes used the same frozen brief, actual component/copy/tests, screenshot and project guidance. Each was limited to 550 words, recorded sources read, choices/costs, semantic boundaries and proposed verification. Controller read every note.

Both conditions already proposed sensible context/effect/evidence grouping and a stable action footer. This is **not** evidence that ordinary layout principles are missing. Most proposed earlier signed feedback; several moved reload exclusively into failures, sometimes while claiming no behavior change. Those are prototype decisions requiring explicit scope, not a reason to claim all baseline output is bad.

All five current notes read the task-to-layout reference. None consulted actual fuller Wondel or Impeccable knowledge sections; one read the optional bridge only. The maintained source audit had provenance but no offline substantive source path. A link-graph packaging test failed before the change because the requested resources were unreachable. That is the demonstrated retrieval/availability gap. Citation counts alone do not demonstrate design quality.

## Intervention

One conditional link in frontend-direction leads to a selection index and two maintained, licensed substantive adaptations (approximately 3,200 words combined). Relevant source sections retain reasoning/examples/tables; upstream scoring, unrelated orchestration and unavailable deep links are omitted. File headers identify qualified universal claims and corrected contrast units. Impeccable remains discovered in the project or runtime and unvendored; knowledge consultation and actual command execution are distinct.

The implementation skill is unchanged: approved target fidelity and its existing optional Impeccable bridge remain applicable. This delivery does not re-open approved targets or add ceremony to mechanical edits.
