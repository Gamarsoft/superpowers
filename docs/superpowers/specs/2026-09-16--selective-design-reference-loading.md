# Selective design reference loading

Revision 1, 2026-09-16. Authority: the human requested testing and integration of fuller Refactoring UI, Design of Everyday Things and optional Impeccable references, using the real DashPark Credipark manual adjustment dialog. This records that authorized scope; it does not approve a new production dialog.

## Delivery

Make relevant, substantive source sections available from the maintained frontend-direction workflow without relying on evaluation folders or a network fetch. Keep project/product context, approved design targets, business rules and the invoking workflow authoritative. Consult only sections relevant to the actual unresolved decision; retain examples and reasoning rather than replacing them with another compact recipe. Impeccable remains optional and project-discoverable. Reading knowledge is distinct from executing its commands.

Use the real manual adjustment dialog to compare the current workflow with source-assisted direction. Inspect its runtime and source, preserve synthetic comparison artifacts and show the rendered alternatives. Assess concrete task clarity, hierarchy, density, action association, responsive behavior and feedback. Record adverse and neutral results as well as gains; one comparison cannot establish universal design superiority.

The current dialog permits preview and submission independently once all required evidence is complete. Preserve that contract, six reason meanings, signed minor-unit amount rules, server authority, preview invalidation, unchanged-retry identity, error retention, close/reload behavior and permission boundaries. Proposed changes to feedback timing or focus must be identified. Never submit a real adjustment during this evaluation.

## Boundaries

No production Gateway changes, new dependencies, automatic helper installation, upstream PR, or global design-system rewrite. Existing packet approval and handoff conventions stay intact. Existing approved designs do not reopen merely because references exist. A mechanical edit does not gain a design exploration ceremony. Missing optional references must not block normal work or be represented as consulted. Source defects identified in the maintained source audit remain excluded/corrected; preserve source provenance and licenses.

## Acceptance

1. Baseline and candidate evidence distinguish source retrieval/application from visual preference.
2. Maintained references are reachable without ignored evaluation artifacts; actual sections can be selected and applied in a fresh context.
3. The manual adjustment comparison uses the same behavior, data and DashPark design guidance, with desktop, short-height and narrow inspection and synthetic interaction checks.
4. The candidate preserves authority and remains usable without Impeccable. No unsupported helper, accessibility or design-quality claims.
5. Focused resource/packet checks and independent review pass before delivery. Human preference can determine the prototype to develop further; it is not a prerequisite to honestly implementing a tested reference-access capability.
