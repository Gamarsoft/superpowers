# Choir practice aid — neutral spec draft

For the user's mother, make starting a rehearsal on her existing tablet possible without help. The first experiment supports choosing one song, reading a short practice prompt, marking today's attempt, and seeing the last seven days.

### Decisions and making choices

**User decisions:** calm tone; no implication of failure after a missed day; no accounts, cloud sync, scores or notifications. Local data loss is acceptable.

**Delegated agent calls:** deliver a browser-based page using HTML, CSS and JavaScript, without a framework. This avoids a platform-specific installation for a small experiment. Keep songs and short prompts bundled with the page; save attempts locally in the tablet's browser. This gives up cross-device access and durable recovery, consistent with the experiment's boundary.

**Unverified assumptions:** the tablet has a browser that can run the page and retain local storage between visits. Its OS and browser are unknown; check the actual device before implementation commits to browser APIs. Song titles and practice prompts still need to be supplied. Assume the tablet's local calendar date defines “today”; make that assumption visible during user review.

### Behavior and examples

- Choose a song to display its short practice prompt and today's marking action. There is no editing or song-management workflow in this slice.
- Marking records an attempt for that song and date. Repeating the action does not create duplicate marks.
- Show today and the preceding six local calendar dates. A date without a mark is neutral, with no score, streak, failure label or warning.
- Example: choosing a song displays its prompt; marking today shows today's attempt in the seven-day view.
- Example: returning after two missed days retains earlier attempts without a reprimand or reduced score.
- Example: if local data is lost, start with an unmarked seven-day view; no recovery or account setup is required.
- If saving fails, keep the practice prompt usable and clearly say the mark was not saved.

### Copy contract

Use “Choose a song”, “Today's practice”, “Mark today's attempt”, “Attempt recorded”, and “Your last seven days”. For an empty history: “Your practice marks will appear here.” For a save failure: “Your attempt couldn't be saved. You can still practise.” Each day needs an accessible label containing its date and whether an attempt was recorded. Use locale-formatted dates; leave enough room for longer song titles and labels.

The actual song prompts are a content dependency, not permission to invent rehearsal instructions. No additional loading, permission or destructive-confirmation flow is required by this slice.
