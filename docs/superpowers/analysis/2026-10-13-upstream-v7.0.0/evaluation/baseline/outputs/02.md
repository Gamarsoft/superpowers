**User and outcome.** A personal practice aid for your mother on her existing tablet. Success means she can choose a song and start a rehearsal without help. This is a first experiment; local data loss is acceptable.

**First delivery boundary.** Choose one song, read a short practice prompt, mark today's attempt, and view the last seven days. No accounts, cloud sync, scores, notifications, or streaks.

**Chosen direction and visible assumptions.** Use a small tablet browser app with plain HTML, CSS and JavaScript and local storage. This is a delegated implementation choice: it keeps the experiment small and avoids an app-store installation. It gives up native integration and cross-device recovery. Assume her tablet has a modern browser and that a small predefined song list and one short prompt per song are sufficient. Tablet model/browser and initial song content remain unverified dependencies; they must be checked before implementation, without a framework comparison.

**Behavior.** Opening the aid offers song selection. Selecting a song shows its practice prompt and today's attempt action. Marking an attempt records it locally for that song and calendar day; tapping again does not create another attempt. Show today and the previous six local calendar days for the selected song. Missed days remain neutral and do not erase earlier attempts. Closing and reopening retains records while browser storage remains available. If records are lost, start with an empty history. A failed save must not show a successful attempt.

**Proposed copy contract.** Song selector: “Choose a song.” Attempt action: “Mark today's practice.” Saved state: “Practice recorded.” History: “Last seven days.” Empty history: “Your practice will appear here.” Save failure: “Couldn't save your practice. Please try again.” Use readable local dates; no failure labels, rankings or missed-day warnings. Visible text and accessible action labels must agree. These strings are draft inputs for approval.

**Acceptance examples.** Selecting a song reveals its prompt without sign-in. Marking today twice shows one recorded day. Yesterday with no attempt has no negative message. Reopening preserves saved attempts when storage is intact. A save failure shows the error and leaves today unrecorded. Your mother can complete selection and start practicing without assistance.
