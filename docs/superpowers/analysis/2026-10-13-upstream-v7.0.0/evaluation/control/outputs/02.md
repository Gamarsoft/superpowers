# B

## Choir practice aid — first experiment

**Purpose:** Help the user's mother begin a choir rehearsal independently on the tablet she already owns.

**Behavior:** She chooses one song, sees a short practice prompt for it, marks today's attempt, and can see her practice record for the last seven calendar days. A missed day is shown neutrally, without failure language or a broken streak. The experience should feel calm and easy to use.

**Boundary:** Personal use on one tablet. No accounts, cloud sync, scores, or notifications. Practice data stays on the device. Losing local data is acceptable for this experiment.

**Visible assumptions:** The first experiment can use a small supplied song list and one prepared prompt per song. The seven-day record shows attempts for the selected song, including today. Marking an attempt records that day's practice without requiring a rating. The tablet's local date defines “today.” I assume its browser can support local storage; the tablet model and browser remain unknown and must be checked before implementation. Delivery technology, language, and framework are implementation choices delegated to the builder.

**Acceptance examples:**

- Choosing a song displays its practice prompt and seven-day record.
- Marking today's attempt shows an attempt for today; marking again does not create a duplicate.
- Returning on the same device retains the record while local storage remains available.
- A day without an attempt uses a neutral state and does not prevent starting practice.

**Success check:** On her tablet, she can choose a song and begin rehearsal without help. This draft has not yet been approved.

The action is absent when no unfinished tour exists. It works offline and does not alter downloaded audio or saved progress merely by showing or selecting the action.
