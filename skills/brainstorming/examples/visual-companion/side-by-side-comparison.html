Visible trade-off summary

Rail layout changes the reading pattern

Persistent left navigation keeps sequence and recovery visible, but it permanently spends horizontal space to do it.

Single column changes the scanning pattern

Full-journey visibility is stronger, but progress context drifts off-screen once users are deep inside the flow.
