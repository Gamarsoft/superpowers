# Mobile Visual Quality Checklist

Use this reference when defining visual direction or improving mobile polish.

## Aesthetic Direction

Choose one dominant product feel and execute consistently:

- calm and reliable
- premium and restrained
- playful and expressive
- utilitarian and dense
- editorial and content-led
- safety-critical and reassuring
- service-oriented and helpful

Do not mix several moods because a prompt asked for "modern".

## Hierarchy

- The primary action should be obvious in 3 seconds.
- One visual anchor should lead each screen.
- Secondary actions should not compete with the primary action.
- Metadata should support scanning but remain readable.
- Repeated list rows should align key values consistently.

## Typography

- Use restrained type scales on compact screens.
- Reserve hero-sized type for true first-screen anchors.
- Use weight and hierarchy before adding colors.
- Make numerals, prices, dates, and statuses easy to compare.
- Check translation expansion and increased text scale.

## Spacing and Surfaces

- Use spacing to show relationships: tight within groups, wider between groups.
- Avoid nested cards and card-heavy page sections.
- Prefer borders, dividers, and surface contrast before heavy shadows.
- Keep radii consistent and modest unless the brand requires otherwise.
- Respect safe areas and bottom controls.

## Color and Status

- Use color roles: primary action, secondary action, surface, status, warning, destructive, success.
- Avoid one-note palettes where every element is a shade of the brand color.
- Use status colors only for real state.
- Do not put legal, price, error, or safety text in low-contrast gray.

## Motion and Feedback

- Motion should clarify navigation, state change, progress, or confirmation.
- Prefer short, native-feeling transitions.
- Respect reduced motion.
- Do not use animation to compensate for unclear hierarchy.

## Pattern Mining

- Use Mobbin/Pttrns-style references to extract conventions, screen order, state coverage, and control placement.
- Do not copy another app's visual identity, brand expression, layout exactness, or proprietary flow.
