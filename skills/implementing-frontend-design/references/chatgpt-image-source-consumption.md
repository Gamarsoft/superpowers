# ChatGPT Images Source Consumption

Historical image-pack consumption is retired. Leave historical files and paths untouched as reference material only. Use this reference only for explicitly requested image-based concepts retained with approved scoped intent in a current version-2 packet. No image pack bypasses the shared v2 validation, approval or required runtime-evidence gates.

## Rules

- Open the exact approved files named in the packet.
- Confirm each image has intent: `visual-truth`, `semantic-guidance`, or `reference-only`.
- For `visual-truth`, compare runtime output against layout, surfaces, typography, spacing, hierarchy, and key states.
- For `semantic-guidance`, implement the workflow, hierarchy, content priority, or state behavior while preserving the product system.
- Ignore `reference-only` images for acceptance unless the packet promotes them.
- Do not copy generated code or UI text from images unless the copy source approves it.

## Verification

Record:

- image files used
- intent mode per image
- pass/mismatch/waived checklist for binding items
- runtime evidence gathered
- copy or accessibility mismatches
