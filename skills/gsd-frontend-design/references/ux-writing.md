# UX Writing

Use copy to preserve product terminology and make actions legible.

## Brownfield defaults

- Reuse existing product terminology.
- Prefer outcome-based action labels.
- Keep operational language explicit rather than cute.
- Preserve translation and localization patterns already used by the product.

## Action labels

Prefer labels that tell the user what will happen:

- `Save changes`
- `Assign valet`
- `Close cash`
- `Keep editing`

Avoid vague labels like:

- `OK`
- `Submit`
- `Yes`
- `No`

## Errors and empty states

Good error copy should tell the user:

1. what happened
2. what they can do next

Empty states should:

1. acknowledge the empty condition
2. explain the next useful action

## Terminology consistency

Pick one term and keep it stable across the same workflow.

Do not vary labels for style.

## Destructive and risky actions

- name the consequence clearly
- make the confirm action specific
- do not soften a destructive action with vague wording

## Accessibility and localization

- icon-only controls need accessible names
- avoid placeholder-only instructions
- leave enough room for translation expansion
- avoid copy that depends on hidden context to make sense
