# Frontend Packet Files

Default location (existing approved layouts also work):

```text
docs/superpowers/specs/
  YYYY-MM-DD--<slug>--frontend-direction.md
  YYYY-MM-DD--<slug>--frontend/
    brownfield-ui-extraction.md
    screen-index.md
    concepts/       # actual generated outputs and prompt provenance
    prototype/      # retained source, launch/state notes, final version
    screenshots/    # baseline and final desktop/narrow/state captures
```

Standalone brief lives in the packet. An approved neutral spec/follow-on is linked when supplied; a GSD handoff is supplemental only for an already confirmed GSD route.

Keep final binding sources and captures durable and recoverable; decide deliberate version-control retention according to project policy. Transient logs/traces are local by default. Historical `chatgpt-image-2/` images and prompts remain readable; this workflow no longer authors upload packs or asks humans to generate externally.
