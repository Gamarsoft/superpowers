# UX copy

Use [writing-ux-copy](../../writing-ux-copy/SKILL.md) as a reference for the affected audience and languages.

Trace the affected wording to the state, action, or recipient it describes. Read the label or message with the surrounding controls and representative values. Include an accessible name or localized string when that is what the person encounters.

In the existing coverage table, cite the wording and the behavior you checked. For a finding, show what someone could reasonably misunderstand or do as a result, and how the diff caused it. Keep approved terminology that fits the audience.
